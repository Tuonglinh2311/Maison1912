Tổng quan

Bản quản lý chạy trên máy tính, chưa có đăng nhập an toàn hoặc đồng bộ Internet. Không công khai đường dẫn Admin và không nhập dữ liệu khách thật.

Hướng dẫn nhanh

1. Thêm căn và nhiều ảnh → 2. Chọn trạng thái nhanh → 3. Đánh dấu ngày trống/đã kín trên lịch → 4. Thiết lập Messenger/LINE → 5. Mở trang khách để kiểm tra.

Lịch trống theo ngày

Nhấn vào từng ngày để chuyển lần lượt: chưa xác nhận → còn phòng → đã kín → chưa xác nhận. Có thể đánh dấu nhiều ngày cùng lúc bằng khoảng ngày bên dưới.

Cập nhật hàng loạt

Kênh để khách nhắn tin

Nhập ít nhất một kênh. Website chỉ mở ứng dụng nhắn tin của khách; không lưu tin nhắn hay thông tin cá nhân.

Sao lưu và khôi phục

Dữ liệu và ảnh được lưu trong bộ nhớ trình duyệt, có thể bị mất khi xóa dữ liệu trình duyệt. Hãy sao lưu định kỳ. Ảnh nhiều có thể làm file sao lưu lớn.

Sau khi chỉnh phòng/lịch, nhấn “Xuất dữ liệu đăng GitHub Pages”, rồi thay file public-data.js trong kho GitHub. Không tải admin.html lên GitHub Pages.

Ảnh được nhúng vào file dữ liệu: nếu nhiều ảnh, file có thể rất lớn và GitHub có giới hạn kích thước. Hãy giảm số ảnh hoặc dùng URL ảnh được lưu ở nơi công khai.
